# Transfer Solution

Estrutura com backend (.NET 9 Web API + SignalR + EF InMemory) e frontend (Blazor WebAssembly).

- Frontend: http://localhost:3000
- Backend: http://localhost:5000 (Swagger disponível)

Para rodar com Docker:

```bash
docker-compose up --build
```

Observações:
- Os projetos foram criados para referência e exemplo. Ajuste versões de pacotes se necessário.
- Testes estão incluídos como esqueleto (backend com integração básica; frontend com bUnit).
